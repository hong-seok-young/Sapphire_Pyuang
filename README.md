# Sapphire (플로팅 시계)

길드 Sapphire의 아이모 위키 앱입니다. 안드로이드 앱은 게임(아이모 등) 위에 **초 단위 시계**도 띄워 줍니다.
제작: 퓨앙 (Sapphire)

- **웹앱 (아이폰, 안드로이드)**: https://sapphire-guild.pages.dev — 아이폰은 Safari, 안드로이드는 Chrome에서 열고 '홈 화면에 추가'
- **안드로이드 앱**: 아래 설치 방법. 같은 위키에 게임 위 시계와 타이머가 더 있습니다.

## 기능
- **위키 첫 화면**: 앱을 열면 길드 위키 웹앱이 그대로 뜸 (두 앱의 정보가 늘 같음). 맨 위 제목이 앱 안에서는 'Sapphire app', 브라우저와 홈 화면 웹앱에서는 'Sapphire web'. 시계 설정, 게임 위에 띄우기, 타이머 설정, 웹앱 링크 보내기, 새로고침은 아래 탭 '⏰ 앱'에서 엶 (앱 안에서만 보임). 바깥 링크는 브라우저로 열림
- 다른 앱 위에 `HH:mm:ss` 시계 오버레이 (초가 바뀌는 순간에 맞춰 갱신)
- 기본은 그림자·배경 없이 작은 글자만 표시. 잘 안 보이면 글자 색을 바꾸거나 배경 진하기를 올리면 됨
- **게임 연동**: 고른 게임(설치된 아이모 자동 감지)이 화면 앞에 있을 때만 시계 표시, 게임을 끄면 사라짐. '사용 정보 접근' 허용 필요, 허용 전에는 항상 표시('시계 켜기'를 누르면 허용 방법 안내). 이 앱 화면에서는 위치나 모양을 바꿀 때만 잠깐 표시. v1.12에서 뺐다가 v1.14에서 되살림
- **게임 위 위키 창**: 게임을 끄지 않고 위키를 작은 창으로 봄 (아이모는 다른 앱으로 넘어가면 접속이 끊김). 시계를 눌러 '📖 위키 띄우기', 또는 아래 탭 '⏰ 앱'의 '게임 위에 띄우기'. 제목을 끌어 옮기고 ⤢로 크기 변경, —로 접기, ✕로 닫기. 바깥 링크도 창 안에서 열림
- **빠른 설정 버튼**: 알림창 빠른 설정에 'Sapphire 시계' 버튼을 넣어 두면 한 번 눌러 시계를 켜고 끔. 시계 설정의 '빠른 설정에 시계 버튼 넣기'로 추가 (안드로이드 13 이상은 시스템 추가 창, 그 전에는 직접 넣는 방법 안내)
- 재부팅이나 업데이트 뒤에도 켜 두었던 시계가 자동으로 다시 켜짐
- **타이머**: 게임 중 시계를 누르면 내가 만든 타이머 목록이 떠서 바로 시작 (예: 보스 30분). 남은 시간이 시계 아래에 뜨고, 곧 끝나면 주황색, 끝나면 빨간색으로 깜빡이며 진동·소리. 정해진 시각 알림(매일 21:00 등)도 지원. 게임 밖에 있을 땐 폰 알림으로 알려 줌. 게임을 읽지 않고 현재 시각만 보고 동작
- **보스·네임드 젠 타이머**: 길드 위키의 재부활 시간(iOS 님 드랍표)을 받아 와서, 시계를 누르면 사냥터를 펼쳐 방금 잡은 몬스터를 골라 시작. 10분 넘게 걸려 다시 나오는 몬스터만, 잡을수록 줄어드는 보스는 고정되는 마지막 값으로 셈. 매일 정해진 시각에 나오는 몬스터는 다음 등장 시각까지 셈
- 시계를 끌어서 이동 + 설정 화면의 가로/세로 슬라이더로 이동 (상태바에 가려 드래그가 안 될 때)
- 기본 위치는 상태바 바로 아래 가운데 (상태바와 겹치면 터치가 상태바에 먹힘)
- 글자 크기 / 글자 색 / 24시간제 / 날짜 표시 옵션, 위치 고정(드래그 잠금)
- 포그라운드 서비스로 동작해서 게임 중에도 안 꺼짐 (알림에서 바로 끄기)
- **알림 숨기기**: 알림창의 '시계 실행 중', '다른 앱 위에 표시 중' 알림을 끄는 설정으로 바로 이동. 꺼도 시계는 그대로 보임 (두 알림 모두 안드로이드 규칙이라 앱이 직접 없앨 수는 없음)
- **앱 내 업데이트**: 앱을 열면 GitHub 릴리스에서 새 버전을 확인하고, 받아서 설치까지 진행. 안드로이드 12 이상은 '이 출처 허용'을 한 번 켜 두면 그다음부터 묻지 않고 설치함 (앱이 잠깐 닫혔다가 다시 열림, v1.16부터). 받는 동안 앱을 뒤로 보냈으면(게임 위에 띄우기 등) 게임 중에 닫히지 않게 다음에 앱을 열 때 설치

## 게임 안전 원칙
아이모 운영 측은 외부 프로그램으로 게임에 영향을 주면 계정을 정지한다고 안내합니다. 그래서 이 앱은:
- 게임 화면을 읽지 않고, 게임에 입력을 보내지 않고, 게임 파일·메모리·통신에 손대지 않습니다.
- 화면 위에 시간만 따로 그립니다. 게임 연동은 안드로이드에 "지금 맨 앞에 떠 있는 앱이 무엇인지"만 묻습니다.
- v1.5에 잠깐 있던 화면 인식 기능은 v1.6에서 완전히 뺐습니다.
- 그래도 판단은 운영 측이 합니다. 걱정되면 컴투스 고객센터에 먼저 물어보세요.

개발 규칙 전문은 [CLAUDE.md](CLAUDE.md)에 있습니다.

## 설치
1. `FloatingClock-v1.x.apk` 를 폰에 복사해서 설치 (출처를 알 수 없는 앱 설치 허용 필요)
2. 앱 실행 → 아래 탭 **⏰ 앱** → **시계 설정** → **권한 설정 열기** → "다른 앱 위에 표시" 허용 (로그인 전에는 로그인 화면의 '⏰ 시계 설정' 버튼)
3. **시계 켜기** → 홈으로 나가서 게임 실행

처음 업데이트할 때 한 번 "이 출처의 앱 설치 허용"을 켜 달라는 화면이 뜹니다. 허용 후 다시 업데이트를 누르면 됩니다.
그다음부터는 (안드로이드 12 이상, v1.16 이상) 앱을 열 때 새 버전을 저절로 받아 설치하고, 앱이 잠깐 닫혔다가 다시 열립니다.
위키, 챗봇, '앱' 탭처럼 웹으로 그리는 화면은 APK 업데이트 없이 웹 배포만으로 바뀝니다.

## 업데이트 배포 (개발자용)
1. `app/build.gradle.kts` 에서 `versionCode` 를 1 올리고 `versionName` 을 바꿉니다 (예: 1.2)
2. `publish.cmd "변경 내용"` 실행 → 빌드 후 GitHub 릴리스 `v1.2` 가 만들어지고 APK 가 첨부됩니다
3. 폰에서 앱을 열면 "새 버전 v1.2" 안내가 뜹니다

배포 저장소: `https://github.com/hong-seok-young/Sapphire_Pyuang` (`UpdateChecker.REPO`). 공개 저장소여야 폰이 로그인 없이 APK를 받을 수 있습니다.

### 서명 키 주의
업데이트는 **같은 서명 키**로 만든 APK만 덮어쓰기 설치가 됩니다.
키는 `keystore/floatingclock.jks` + `keystore.properties` 에 있고 `.gitignore` 로 커밋에서 제외됩니다. **백업해 두세요.** 잃어버리면 기존 사용자는 앱을 지우고 다시 설치해야 합니다.

## 빌드 (Windows)
JDK 17 과 Android SDK 가 `C:\Users\Administrator\android-dev` 에 포터블로 설치되어 있습니다.

```bat
build.cmd
```

> 다른 PC에서 빌드할 때는 `local.properties` 의 `sdk.dir` 을 그 PC의 SDK 경로로 바꾸세요.
> 안드로이드 스튜디오로 폴더를 열어도 바로 빌드됩니다.

### 이 PC에서 Gradle 8.4 / AGP 8.3.2 를 쓰는 이유
이 PC의 보안 프로그램(AhnLab V3 등)이 새로 만들어진 jar 파일을 한참 잡고 있어서,
Gradle 8.5 이상이 쓰는 "임시 폴더 → 캐시 폴더 이동(rename)" 방식이
`Could not move temporary workspace ... AccessDeniedException` 으로 실패합니다.
Gradle 8.4 는 폴더 이동 없이 캐시에 바로 쓰기 때문에 문제가 없습니다.
백신 실시간 검사 예외에 `C:\Users\Administrator\android-dev` 를 추가할 수 있다면 최신 Gradle/AGP 로 올려도 됩니다.

## 웹앱 (web/)
아이폰, 안드로이드 모두 쓰는 위키 웹앱입니다. 주소: **https://sapphire-guild.pages.dev** (Cloudflare Pages, `npm run deploy`). 사냥터, 몬스터 드랍, 아이템 검색(초성 검색 포함), 장비, 육성 공략, 스킬, 조합책 등. 안드로이드 브라우저에서는 첫 화면의 '안드로이드 앱 받기'(`#/app`)에서 앱 APK를 받는다.
사냥터 화면에는 몬스터 카드와 함께 원글의 지도, 옆 사냥터로 가는 길, 이동, 퀘스트, NPC, 참고, 보상 칸이 그대로 보인다 (원글이나 카페를 따로 열 필요 없음).
안드로이드 앱은 정보, 챗봇 화면으로 이 웹앱을 그대로 띄웁니다 (두 앱을 같이 고치는 규칙은 [CLAUDE.md](CLAUDE.md)).

```bash
cd web
npm install
pip install -r scripts/requirements.txt   # 처음 한 번
python scripts/build_data.py              # ../자료 -> public/data, public/img (3~4분)
npm run dev                               # http://localhost:5173
npm run build                             # 배포용 dist/
npm run deploy                            # 빌드 + Cloudflare Pages(sapphire-guild)에 올리기 (처음엔 npx wrangler login)
```

보통은 직접 배포하지 않아도 됩니다. `main` 에 `web/` 이 바뀌어 올라오면 GitHub Actions 가 자동으로 배포합니다 (아래 '길드 계정'의 자동 배포).

- 위키 자료(`자료/`, `web/public/data`, `web/public/img`)는 git에 올리지 않습니다. 자료 출처: 아이모 원클릭 드랍표 (Made by iOS).
- 글꼴: [갈무리](https://github.com/quiple/galmuri) (SIL OFL 1.1)

### AI 챗봇
위키의 '💬 챗봇'(`#/chat`)에서 육성법, 장비, 드랍, 사냥터를 물어보면 Claude 가 위키 자료를 보고 답합니다.

- 질문에 나온 아이템, 몬스터, 사냥터와 제목이 맞는 글(육성 공략 등), 사냥터 목록을 화면이 골라 함께 보냅니다 (`src/chat.ts`).
- 📷 로 갤러리에서 직접 고른 게임 스샷(2장까지)을 보내면 보고 조언합니다. 앱은 화면을 캡처하지 않고, 답은 읽는 글로만 보여 줍니다. 게임 위 위키 창에서는 사진 버튼이 없습니다.
- 서버(`functions/api/chat.ts`)가 로그인과 하루 질문 수(한 사람 20번)를 확인하고 답을 조금씩 흘려보냅니다. 모델은 그 파일의 `MODEL` 한 줄(기본 Claude Opus 5.5)입니다.
- 필요한 것: 저장소 비밀값 `ANTHROPIC_API_KEY` (아래 자동 배포 표). 질문 하나에 대략 몇십 원(스샷이 있으면 조금 더)이 듭니다.

### 길드 랭킹
길드원은 처음 들어올 때 직업(전사, 레인저, 마법사, 무도가)과 레벨, 경험치 %(소수점 3자리, 안 적어도 됨)를 정하고,
레벨이 오르면 '내 정보'(`#/me`)에서 바꿉니다. 경험치 숫자는 본인에게만 보이고, 같은 레벨이면 경험치가 높은 사람이 위입니다.
잘못 고른 직업과 레벨은 오피서 이상이 '길드원 관리'에서 누구 것이든 고칠 수 있습니다.

홈의 '🏆 길드 랭킹'(`#/ranking`)은 메뉴가 넷입니다.
- **레벨**: 게임의 경험치 랭킹 목록 그대로입니다. 1~3위 메달, 직업 엠블럼(1~20위 보라, 21위부터 금색), '내순위' 말풍선을
  제작자가 찍은 게임 랭킹 스샷에서 잘라 썼습니다(비공개 자료 저장소 `이미지/랭킹/`). 직업 필터 단추는 이 앱 디자인에 게임 직업 문양만 넣었습니다.
- **오늘 / 주간 / 월간 성장**: 그 기간(한국 시간 오늘 0시, 이번 주 월요일 0시, 이번 달 1일 0시부터)에 레벨과 경험치가 오른 만큼의 순위입니다
  (레벨 1 = 100%). 레벨, 경험치를 적을 때마다 기록되고, 오른 양만 보이고 경험치 값은 안 보입니다. 1등은 크게 나옵니다.

캐릭터 사진은 '내 정보'에서 올리고 성장 랭킹에 나옵니다. 갤러리에서 스샷을 고르고, 끌고 벌려 캐릭터를 네모에 맞춘 뒤,
배경을 눌러 지워 올립니다. 모두 폰 안에서 하고 자른 캐릭터만 올라갑니다. 캐릭터가 아닌 그림은 오피서 이상이 내릴 수 있습니다.

### 사파이어 중개인
홈의 '💰 사파이어 중개인'(`#/market`)은 길드원끼리 파는 물건 게시판입니다. '팔기'에서 아이템 이름을 치면 위키 아이템이 그림과 함께 뜨고,
장비면 강화(+N)와 속성부여(힘, 민첩, 지능 1~3 / 체력, 마나 10, 20, 30)를 고른 뒤 가격(골드)을 적어 올립니다.
'사기'에서 종류와 이름으로 찾고, 눌러서 정보(요구 레벨, 방어력, 속성부여, 기본 옵션)를 보고 '살래요'를 누릅니다.
누가 사고 싶어 하는지는 판 사람의 '내 판매'에만 보입니다. 실제 거래는 게임 안에서 하고, 현금 거래는 하지 않습니다.

### 길드 계정 (로그인)
위키는 길드원만 로그인해서 봅니다. 로그인 전에는 로그인 화면만 보이고, 위키 자료(`data/*.json`)도 서버가 로그인한 사람에게만 줍니다.

| 역할 | 누구 | 할 수 있는 일 |
| --- | --- | --- |
| 앱개발자 | 퓨앙 | 길드마스터, 오피서, 길드원 계정 모두 |
| 길드마스터 | 마을모금함 | 오피서 임명과 해제, 오피서와 길드원 계정 만들기, 지우기, 비밀번호 초기화 |
| 오피서 | 멍멍, 유어아너, 아홀로틀, 정서, 향단 | 길드원 계정 만들기, 지우기, 비밀번호 초기화 |
| 길드원 | 나머지 | 자기 비밀번호 바꾸기 |

- 계정은 첫 화면의 '👥 길드원 관리'에서 만듭니다. '처음 비밀번호' 칸에 쓰면(예: 123123) 그 비밀번호로 만들거나 초기화하고, 비우면 임시 비밀번호를 자동으로 만듭니다. 어느 쪽이든 그 사람은 처음 로그인할 때 다른 비밀번호로 바꿔야 합니다.
- 비밀번호는 원문을 저장하지 않고 해시만 저장합니다. 로그인은 직접 로그아웃하기 전까지 유지됩니다 (위키에 들어올 때마다 400일로 다시 늘어남. 400일 넘게 한 번도 안 들어오면 다시 로그인).
- 안드로이드 앱(v1.15 이상)은 앱 안 위키에서 로그인하면 보스 목록과 게임 위 위키 창도 같이 로그인됩니다.

**자동 배포 (GitHub Actions)**

`main` 에 `web/` 이 바뀌어 올라오면 `.github/workflows/deploy-web.yml` 이 GitHub 서버에서 비공개 자료 저장소를 받아 위키 자료를 만들고(`build_data.py`), 계정 DB를 준비하고(`scripts/ci-d1.mjs`), Cloudflare Pages 에 올립니다. PC에서 wrangler 로그인을 하지 않아도 되고, 저장소 Actions 탭의 'Run workflow' 로 다시 돌릴 수 있습니다. 저장소 비밀값(Settings > Secrets and variables > Actions) 네 개가 있어야 돌고, 없으면 배포를 건너뜁니다.

| 비밀값 | 내용 |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | Cloudflare > My Profile > API Tokens > Create Custom Token. 권한: Account > Cloudflare Pages > Edit, Account > D1 > Edit |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare 계정 ID (로그인한 대시보드 주소 `dash.cloudflare.com/<계정 ID>/...`) |
| `DATA_REPO_TOKEN` | GitHub > Settings > Developer settings > Fine-grained tokens. Repository access: `sapphire-imo-data` 만, Permissions: Contents Read-only |
| `DEV_PASSWORD` | 계정이 하나도 없을 때 만드는 퓨앙 계정의 첫 비밀번호 (6자 이상). 처음 로그인하면 바꾸게 됨 |
| `FIRST_PASSWORD` | (있으면) 시작 계정 마을모금함(길드마스터)과 오피서 다섯 명을 이 비밀번호로 한 번만 만듦. 처음 로그인하면 바꾸게 됨 |
| `ANTHROPIC_API_KEY` | (있으면) 챗봇이 쓰는 Claude API 키. console.anthropic.com 에서 결제 수단을 넣고 만든다. 없으면 챗봇은 '준비 중' |

- 계정 DB(D1 `sapphire-accounts`)가 없으면 첫 배포가 아시아(apac)에 만들고 표(`schema.sql`)를 넣습니다.
- 임시 비밀번호로 처음 들어오면 비밀번호 바꾸기 화면만 보입니다. 다른 아이디로 잘못 들어왔으면 '◀ 다른 아이디로 로그인'이나 폰의 뒤로 가기로 로그인 화면으로 돌아갑니다.
- 첫 계정은 퓨앙 하나만 만듭니다. 마을모금함과 오피서 다섯 명은 퓨앙이 위키 '👥 길드원 관리'에서 만들고, 화면에 한 번 보이는 임시 비밀번호를 각자에게 따로 알려 줍니다. (공개 저장소라 실행 기록에 비밀번호를 찍을 수 없어서)

**PC에서 직접 배포 (자동 배포를 못 쓸 때, 위키 자료가 있는 PC에서)** (Cloudflare 로그인 필요)

배포 전에는 위키 자료를 새로 만든다 (`npm run deploy` 가 자료가 없거나 예전 모양이면 멈춘다). `자료/`가 없으면 먼저 비공개 저장소를 받는다:

```bash
git clone https://github.com/hong-seok-young/sapphire-imo-data.git 자료
python web/scripts/build_data.py
```

`wrangler` 가 `SELF_SIGNED_CERT_IN_CHAIN` 으로 실패하면(보안 프로그램이 인증서를 바꾸는 네트워크), PowerShell 에서 `$env:NODE_OPTIONS='--use-system-ca'` 를 먼저 실행하고 `npx.cmd wrangler ...` 로 실행한다.

```bash
git pull
cd web
npm install
npx wrangler d1 create sapphire-accounts
```

위 명령이 보여 주는 `database_id` 를 `web/wrangler.toml` 의 `database_id` 자리에 넣은 뒤 이어서:

```bash
npx wrangler d1 execute sapphire-accounts --remote --file=schema.sql
npm run accounts
npx wrangler d1 execute sapphire-accounts --remote --file=accounts-seed.sql
del accounts-seed.sql
npm run deploy
```

- `npm run accounts` 는 퓨앙, 마을모금함, 오피서 다섯 명의 임시 비밀번호를 화면에 보여 줍니다. 각자에게 따로 알려 주세요.
- `accounts-seed.sql` 은 공개 저장소에 올리지 않습니다(.gitignore). 넣은 뒤 지웁니다.
- `wrangler.toml` 의 `database_id` 는 비밀이 아니라서 바꾼 채로 커밋해도 됩니다.
- 로컬에서 로그인까지 시험: `npm run dev:accounts` (로컬 전용 D1, 실제 계정과 별개)

```
web/
  scripts/build_data.py  저장한 카페 글 -> 글 본문 블록, 사냥터, 몬스터, 아이템, 장비 JSON + 그림
  scripts/make-accounts.mjs  처음 계정(앱개발자, 길드마스터, 오피서) 임시 비밀번호와 SQL 만들기
  functions/             로그인 서버 (Cloudflare Pages Functions): api/login, me, password, users, data/_middleware
  server/auth.ts         비밀번호 해시, 세션, 역할별 권한 (functions 가 같이 씀)
  schema.sql, wrangler.toml  계정 DB(D1) 표와 연결 설정
  src/App.tsx            로그인 확인, 화면 전환 (해시 주소), 아래 탭
  src/auth.ts            로그인, 길드원 관리 API 부르기
  src/pages/Login.tsx, Admin.tsx  로그인, 비밀번호 바꾸기, 길드원 관리 화면
  src/pages/             홈, 검색, 사냥터, 몬스터/아이템, 장비, 메뉴/글 보기
  src/Blocks.tsx         원글 표를 종이색 바탕에 그대로 그리기
  src/search.ts          이름, 초성 검색
```

## 참고
- iOS 는 다른 앱 위에 뜨는 오버레이를 허용하지 않아서 안드로이드 전용입니다.
- 시계가 사라지면 설정 → 앱 → Sapphire → 배터리 → **제한 없음** 으로 바꿔 주세요.
- '사용정보 접근 허용' 스위치가 회색(제한된 설정으로 제어됨)이면: 설정 → 애플리케이션 → Sapphire → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 켜기. 스토어 밖에서 설치한 앱에 안드로이드가 거는 기본 잠금입니다.
