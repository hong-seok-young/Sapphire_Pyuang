# 도감 계산기: 시세 비교 계획 (제작자 요청 2026-11-11)

> 다음 세션에서 이어서 한다. 먼저 `CLAUDE.md` 의 '도감 계산기' 절(지금 화면과 자료)과 자료 저장소 `제공/도감_시세.md`(규칙, 스탬프 값, 확인된 사실)를 읽는다.
> 값·계산 숫자는 비공개 자료 저장소에만 둔다 (이 저장소는 공개). 이미 받은 것을 다시 묻지 않는다 (`자료/제공/`, `자료/공식/확률/`, `자료/공식/소식.json`, `자료/도감/` 을 먼저 찾는다).

## 하려는 것
- 지금 도감 계산기(`#/dex`, `src/pages/Dex.tsx`, `data/dex.json`)에 **값**을 더한다: 도감 칸마다 **골드로 장비를 사서 넣기** vs **장비스탬프로 대체 등록** 중 싼 쪽을 추천.
- **아바돈 이벤트 때 기준** vs **이벤트가 아닐 때** 미완료 칸을 다 채우는 총 골드를 나란히, 아끼는 골드도.
- 장비 값은 암거래중개인(게임 거래소) 녹화를 읽은 시세 `자료/시세/암거래중개인/<날짜>/시세.json` 의 `equipment`(장비마다 옵션 무시 최저가, 강화 단계별 최저가, 무기/갑옷류).

## 정해진 규칙 (제작자 2026-11-11, 자세한 것은 `자료/제공/도감_시세.md`)
- 도감용 장비는 옵션 무시, **같은 장비 중 가장 싼 매물**.
- 갑옷류(갑옷·투구·장갑·신발·보조 장비)는 +4 까지 100%, +5 부터 파괴될 수 있다. 무기는 +6 까지 100% (공식 확률 120101·120102 와 같다).
- 강화 칸의 골드 값:
  - 갑옷류 +N(≤4) = 가장 싼 장비 + 마법서 N장 / +5 = (장비 + 마법서 5장) × 2 / +6 = +5 계산값 × 2.5
  - 무기 +N(≤6) = 가장 싼 장비 + 마법서 N장 / +7 = (장비 + 마법서 7장) × 2 / +8 = +7 계산값 × 2.5
  - 도감은 칸의 강화 단계와 같은 장비만 받는다 ('노강'은 노강으로만, CLAUDE.md 도감 계산기 절). 노강 칸은 +0 최저가 그대로.
  - 거래소에 그 강화 단계 매물이 계산값보다 싸면 그 매물 값을 쓴다 (이미 강화된 걸 사는 게 싸면 그쪽). 화면에는 둘 다 보인다.
- 스탬프 칸의 골드 값 = 대체 스탬프 장수(`sg`·`sn`) × 스탬프 1장 값. 아바돈 스탬프 1장 = 일반 50장.
  - 평소: 상점 낱개 값. 이벤트: 봉인된스탬프함 A/B 와 왜곡된수정구 기대값으로 계산한 1장 값 (`자료/제공/도감_시세.md` 표).
  - 플래티넘 → 골드는 플래티넘 상점 설정의 시중 비율(`plat_settings.market`)을 쓴다.
- 칸마다 추천 = min(골드 값, 스탬프 값). '대체 등록 불가' 칸은 골드 값만, 시세 없는 장비는 스탬프 값만 ('시세 없음').

## 만들 것
- [ ] `web/scripts/build_dex.py`: 자료 `시세/암거래중개인/` 의 가장 최근 날짜 `시세.json` 을 읽어 dex.json 장비 칸에 최저가(`p0`: +0, `pp`: 강화 단계별)와 시세 날짜를 붙인다.
      이름은 띄어쓰기 무시로 잇는다 (거래소 이름 = 위키 이름, 예: '워 너클'). 마법서·스탬프 값도 자료에 생기면 같이.
- [ ] `Dex.tsx`: 칸 상세에 '골드로: 장비 N + 마법서 M장 = …' 과 '스탬프로: B 11장 = …', 추천 표시. 목록 줄에는 작게 싼 쪽만.
- [ ] '필요 재료' 위 합계: 평소 vs 아바돈 이벤트 총 골드와 아끼는 골드, 시세 날짜. 이벤트 기간이면 띠로 알림 (공식 소식의 '아바돈 장비 스탬프' 기간).
- [ ] 마법서·스탬프 1장 값을 화면에서 직접 고칠 수 있게 (내가 아는 시세로, localStorage, 손댄 칸 금색: 획득 옵션 칸과 같은 방식).
- [ ] 강화 기대값을 더 정확히 하고 싶으면 확률 시뮬레이터의 `expectedTo`(`src/sim.ts`, 평균 마법서·부서질 확률)로 바꿀 수 있게 남겨 둔다 (지금은 제작자 규칙 ×2, ×2.5).
- [ ] 챗봇: 자료 저장소의 시세·규칙 md 는 저절로 읽는다. '도감 ○○ 채우려면 얼마' 같은 질문이 잘 되는지 시험.
- [ ] 열 때 할 일은 CLAUDE.md 도감 계산기 절 그대로 (패치 내역, 챗봇 안내 등).
