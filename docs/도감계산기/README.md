## 하려는 것
- 도감 칸마다 **골드로 장비를 사서 넣기** vs **스탬프로 등록하기** 중 싼 쪽을 추천한다.
- **아바돈 이벤트 기준으로 채울 때** vs **이벤트가 아닐 때 채울 때** 총비용도 나란히 비교한다.
- 장비 값은 암거래중개인(게임 안 거래소) 시세를 쓴다. 같은 시세를 챗봇 자료로도 쓴다.
- 시세는 제작자가 찍은 거래소 녹화를 개발 PC에서 읽어 날짜별로 적어 둔 것이다.
  앱이 게임 화면을 읽는 것이 아니다 (CLAUDE.md 규칙 그대로. 계산기는 적어 둔 숫자만 쓴다).

## 장비 시세 정하는 법 (제작자 설명)
- 도감용 장비는 **옵션이 전혀 쓸모없다**. 같은 장비 중 **가장 싼 매물** 값만 본다.
- **갑옷류**: +4 까지 100% 성공.
  - +4 = 가장 싼 장비 + 인챈트 4장
  - +5 = (장비 + 인챈트 5장) × 2
  - +6 = 장비 + 인챈트 6장이지만, 보통 **+5 계산값 × 2.5** 로 본다
- **무기**: 같은 방식이고 기준 단계만 다르다.
  - +7 = (장비 + 인챈트 7장) × 2
  - +8 = **+7 계산값 × 2.5**
  - +6 이하는 갑옷류처럼 장비 + 인챈트 N장으로 본다 (100% 성공 구간인지 확인 필요, 아래 '물어볼 것')
- 인챈트 값은 장비 종류(무기용, 방어구용)에 맞는 주문서 시세를 쓴다.

## 스탬프 (제작자 설명)
- **일반 스탬프**와 **아바돈 스탬프**가 있다.
- 아바돈 스탬프는 **아바돈 이벤트 기간에만** 살 수 있다. **아바돈 스탬프 1장 = 일반 스탬프 50장**으로 서로 바꿀 수 있다.
- 보통 이 이벤트가 가성비가 좋다. 그래서 두 경우를 따로 계산한다.
  - 이벤트 기준: 일반 스탬프 1장 값 = min(일반 스탬프 값, 아바돈 스탬프 값 ÷ 50)
  - 이벤트 아닐 때: 일반 스탬프 값 그대로
- 스탬프 값이 플래티넘이면 골드로 바꾸는 비율이 필요하다 (플래티넘 상점의 '시중' 비율을 쓸지 제작자에게 확인).

## 계산기 화면 (안)
- 도감 칸마다: 필요한 장비와 강화 단계, 골드로 살 때 값(어떤 계산식으로 나왔는지 같이), 스탬프로 할 때 값(장수 × 1장 값),
  **추천**(싼 쪽)과 차이.
- 맨 위 합계: 이벤트 기준 총 골드 vs 평소 총 골드, 아끼는 골드.
- 시세 날짜를 같이 보인다. 시세가 없는 장비는 '시세 없음'(스탬프 값만).
- 웹앱 한 곳에서만 만든다 (안드로이드 앱은 웹을 띄우므로 따로 만들지 않는다).
