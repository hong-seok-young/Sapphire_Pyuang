**새 기능에 배지를 달거나 배지가 있는 화면을 고치면 이 규칙을 지킨다.**

## 1. 숫자는 누르는 길을 따라 끝까지 간다

홈 칸(이나 아래 탭)에 숫자가 뜨면, 그 칸을 눌러 들어간 모든 단계에 같은 숫자가 나뉘어 붙어야 한다.

```
홈 칸 3
 └ (갈라지는 칸이면) 1군 2 · 2군 1
    └ 위 단추(탭) '담당자' 2
       └ 아래 단추 '신청' 2
          └ 줄(카드)마다 'N' 또는 그 줄의 수
```

- 한 단계의 숫자 = 그 아래 단추들의 숫자 합. 어느 단계에서도 '어디서 왔는지' 모르는 숫자가 없다.
- 마지막은 줄(글·물건·신청서·카드) 하나. 그 줄에는 그 줄의 수(`ThingDot`)나 빨간 'N'(`NewTag`)을 붙인다.
- 숫자를 글자로 이름에 붙이지 않는다 ('담당자 2' X). 늘 같은 도트 모양 배지(`NewsDot`, 단추 모서리)로.
  '신청함 2'처럼 개수를 이름에 쓰는 것은 '지금 몇 개 있다'는 뜻이라 배지와 따로 둔다.

## 2. 지우는 때

| 종류 | 예 | 사라지는 때 |
|---|---|---|
| 새 일 (본 때로 센다) | 새 글, 댓글, 새 물건, 토론방 글, 대화, 나에게 온 알림 | 그 줄(글·물건·카드)을 열거나 눌러야. 단추를 연다고 지우지 않는다 |
| 할 일 (남은 만큼 센다) | 확인 전 구매 신청, 확인 전 대여 신청, 반납 신청 | 처리하면 (지급 완료·반려·수락·반납). 본다고 지우지 않는다 |

- 새 일은 `src/news.ts` 의 THING_KEYS 단추로 두고, 서버 `/api/news` 의 `things` 에 '키, 단추, 때, 쪽' 줄을 준다. 키는 화면의 줄 하나 ('post:12', 'rapp:5').
  줄을 여는 곳에서 `markThingSeen(키)`, 줄에 `<ThingDot k={키} />`.
- 할 일은 THING_KEYS 가 아닌 단추로 두고 서버가 남은 수를 센다 ('gcoin.staff', 'rent.wait'). 줄에는 `NewTag`.
- 화면에 줄이 없는 새 일(반납이 끝나 쓰는 무기 줄이 없어진 알림 등)은 그 칸을 열 때 본 것으로 적는다 (`useOrphanSeen(단추, 보이는 키들, 칸을 보고 있는지)`).
  안 그러면 어디에도 없는 숫자가 홈에 남는다.

## 3. 군·쪽·직업처럼 갈라지는 곳은 따로 센다

- 한 칸이 둘로 갈라지면(성장코인샵 1군 · 2군) 서버가 따로 센다 ('gcoin.staff1' · 'gcoin.staff').
- 팝니다·삽니다, 직업, 게시판 칸처럼 한 단추 안이 갈리면 things 의 쪽(s)으로 나눠 센다 (`newsSide`).

## 4. 알림에서 줄까지

나에게 온 알림을 배지로 세는 곳(장비대여 신청함)은 알림 주소에 어느 줄인지 붙인다 (`#/rent?v=apps&app=12`, `&item=3`, `&mile=1`).
서버가 그 주소로 키를 만든다. 새 알림을 보낼 때도 줄을 가리키는 주소를 쓴다.

## 지금 배지가 있는 곳

| 홈 칸 | 길 | 끝 (줄) |
|---|---|---|
| 게시판 | 칸 탭(공지·이벤트·자유) · 아이모 소식(전체·공지·점검·이벤트) | 글 줄 `post:` · `imo:` |
| 건의함 | 내 건의함(길드원) · 접수함(운영진) | 글 줄 `post:` |
| 사파이어 중개인 | 목록 · 골드 → 팝니다·삽니다 | 물건 줄 `item:` · 토론방 `talk:` · 골드 줄 `gold:` |
| 길드원 의뢰소 | 모집 중 · 완료 · 내 의뢰 칩 | 의뢰 줄 `req:` |
| 장비대여 | 목록 → 직업 | 무기 줄 `rent:` |
| | 신청함 | 신청서 카드 `mapp:` · 쓰는 무기 줄 `mheld:` · 장부 단추 `mmile` |
| | 운영 → 장비대여 | 확인 전 신청 줄 N (rent.wait) · 신청서 카드 대화 `rapp:` |
| | 운영 → 장비반납 | 반납 신청 줄 (rent.wait) · 반납 대화 `rback:` |
| 성장코인샵 | 1군 · 2군 → 담당자 → 신청 | 신청 줄 N (gcoin.staff1 · gcoin.staff) |
| | 1군 | 받은 코인 팝업 (gcoin.gift) |
| 개발 중 묶음 | 펼치면 안의 칸 | 위와 같음 |

## 시험

배지를 바꾸면 로컬에서 남의 계정으로 새 일을 만들고, 홈 → 단추 → 줄까지 숫자가 같은지, 줄을 열면 위 단계 숫자가 모두 줄어드는지 본다 (320px).
